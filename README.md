# Patient Data Analysis — Python & Healthcare AI

## Overview
Healthcare data analysis project using Python, Pandas and 
Matplotlib to detect clinical anomalies across patient records.

## Features
- Loads and structures patient medical data using Pandas
- Calculates descriptive statistics (mean, min, max, std)
- Detects high-risk patients: elevated BP, glucose, heart rate
- Visualises results with color-coded bar charts

## Tech Stack
- Python | Pandas | Matplotlib | NumPy
- Google Colab | Healthcare Data Analysis

## Background
Built by a certified Healthcare Assistant (UK — NHS & private 
sector) transitioning into AI/Healthcare AI roles.
